Como usar o MeuTerminal

O MeuTerminal é um navegador de sessões para o seu servidor: terminais, páginas e arquivos em abas, iguais no celular e no computador. Os terminais continuam rodando no servidor quando você fecha o app.

01 Começando

  • Entrar: email e senha, os definidos no servidor em AUTH_EMAIL e AUTH_PASSWORD. Se a verificação em duas etapas estiver ligada, o app também pede o código de 6 dígitos (veja Login e 2 etapas).
  • Instalar como app no celular: abra o endereço no Chrome (Android) ou Safari (iPhone) e use "Adicionar à tela inicial". Ele abre em tela cheia, como um app.
  • Menu ⋮ no canto superior direito: novas abas, comandos rápidos, tema, configurações, este guia e sair.
  • Barra de status (embaixo): conexão, pasta atual, programa rodando, branch do git e hora. No celular, o botão de lista à direita troca de aba.

Terminal

Shell real no servidor. Continua rodando mesmo com o app fechado.

Navegador

Veja o projeto que está rodando no servidor (localhost:5173) sem expor portas.

Arquivos

Gerenciador de arquivos do servidor e do Google Drive: ver, editar, enviar, baixar.

02 Abas

As abas ficam salvas no servidor: abrindo o app em outro aparelho, você vê as mesmas abas, na mesma ordem.

Criar

  • + na barra de abas abre a galeria de apps: Terminal, Navegador, Arquivos, Anotações, Agente (nova conversa) e Vibecoding (novo projeto), igual na tela inicial de um celular. Terminal, Navegador e Arquivos abrem um formulário (nome e a pasta ou o endereço); Anotações, Agente e Vibecoding abrem direto, sem formulário. Dá para reabrir abas fechadas recentemente na mesma tela.
  • Pelo menu ⋮ ou pelos atalhos: Ctrl+Alt+T terminal, Ctrl+Alt+B navegador, Ctrl+Alt+E arquivos — essas criam a aba direto, sem passar pela galeria.

Sem nenhuma aba aberta (primeiro acesso, ou depois de fechar a última), o MeuTerminal fica nessa galeria em vez de abrir algo sozinho: você escolhe o que abrir.

Organizar

  • Menu da aba: botão direito no computador ou toque longo no celular. Tem: duplicar, renomear, fixar, mover e fechar outras ou à direita. Numa aba de terminal, "Abrir pasta atual nos Arquivos" abre um gerenciador na pasta onde o shell está.
  • Arrastar uma aba muda a ordem. Abas fixadas ficam sempre à esquerda e não fecham com "Fechar outras".
  • Duplo clique no nome (ou Ctrl+Alt+R) renomeia.

Fechar e reabrir

Fechar a aba (✕) encerra o processo dela: o shell e o que estiver rodando nele. Fechar o app, o navegador ou o celular não encerra nada.

Logo depois de fechar aparece "Reabrir" no aviso. Também dá para usar Ctrl+Alt+Shift+T ou a lista "Sessões recentes" da página de nova sessão. A aba reaberta começa um shell novo na mesma pasta.

03 Terminal

É um terminal de verdade (bash no servidor, com Starship). Programas como vim, htop, claude e npm run dev funcionam normalmente. Ao voltar para uma aba, a tela aparece como estava.

Barra de atalhos (celular)

Aparece acima do teclado quando você digita no terminal:

  • ESC TAB CTRL ALT e as setas. CTRL/ALT valem para a próxima tecla (ex.: CTRL e depois c = Ctrl+C).
  • … mostra mais teclas: HOME, END, PGUP, PGDN, | / ~ - $ & >.
  • ⚡ Comandos rápidos: lista de comandos salvos. Cadastre em Configurações → Comandos rápidos; ficam no servidor, iguais em todo aparelho. Cada um pode só digitar ou já apertar Enter.
  • 📋 Colar: um toque cola o que está copiado no celular. Segure para ver "Copiados recentemente", o histórico, que fica só neste aparelho.
  • 🎤 Microfone: dita o texto por voz e digita no terminal.

Em Configurações → "Barra de atalhos" dá para deixar a barra sempre visível.

Gestos

  • Arrastar com 1 dedo rola o histórico. Dentro de programas de tela cheia (vim, htop, Claude Code), rola o próprio programa, no ponto onde está o dedo.
  • Toque com 2 dedos é o botão direito: abre o menu com colar, copiar tudo, comandos e copiados recentes.

Outros

  • Ctrl+F busca no terminal.
  • Botão de tela cheia (ou Ctrl+Alt+F): no iPhone vira "modo foco", que esconde a interface.
  • Configurações: fonte, altura da linha, cursor, histórico de rolagem, tema e pasta inicial dos terminais. Essas preferências ficam salvas por aparelho.

04 Navegador

Um navegador (Chromium) roda no servidor e aparece na aba como imagem. Serve para ver o projeto que você está rodando lá: localhost é o próprio servidor, sem abrir portas para a internet.

  • Digite 5173, localhost:3000 ou um site na barra de endereço.
  • O botão de atividade lista as portas abertas no servidor (projetos rodando). A página de nova aba também mostra essas portas.
  • Toque é clique, arrastar rola e 2 dedos é o botão direito. O botão de teclado abre o teclado do celular para digitar na página.
  • O botão de engrenagem troca o tamanho (da aba, celular 390×844 ou desktop 1280×800) e a qualidade da imagem. Use "Leve (4G)" em conexões ruins.
  • Logins e cookies das páginas ficam salvos no servidor.

Tela dividida (tipo Live Server do VS Code)

  • No menu da aba (botão direito ou toque longo), escolha Dividir tela com… e depois outra aba, uma aba nova de navegador ou os arquivos da pasta. O menu ⋮ também tem "Dividir tela…".
  • No computador as duas abas ficam lado a lado. No celular em pé, ficam uma em cima da outra, com a página em cima e o terminal embaixo, perto do teclado. Arraste o divisor para mudar o tamanho; duplo clique volta para metade/metade.
  • O painel em que você tocou por último é o que recebe o teclado, a busca e a barra de status. Ele fica marcado com uma linha roxa.
  • Tocar numa aba que não está na divisão mostra só ela; voltar para uma das duas mostra a divisão de novo. Para desfazer, use "Desfazer divisão" no menu da aba.

Recarregar ao salvar

Na aba de navegador, engrenagem → Recarregar ao salvar arquivos… e escolha a pasta do projeto: a página recarrega sozinha sempre que um arquivo dela muda. Aparece o selo ao vivo na barra. Sites só com HTML/CSS/JS nem precisam de servidor: a prévia serve a pasta direto, e só o navegador do app acessa.

05 Arquivos

Gerenciador de arquivos do servidor e das nuvens configuradas no rclone (Google Drive etc.). Abra pelo ⋮ → "Gerenciador de arquivos" ou com Ctrl+Alt+E.

Navegar

  • Painel lateral (botão à esquerda da barra): Início (sua home), Raiz do servidor, Nuvem (remotes do rclone) e Favoritos.
  • O caminho no topo é clicável. A seta ↑ sobe uma pasta; no computador também há voltar e avançar.
  • A aba lembra a pasta em que está, em todos os aparelhos.

No celular

  • Toque abre pasta ou arquivo.
  • Toque longo seleciona. Depois disso, cada toque adiciona ou tira da seleção. A barra embaixo tem copiar, recortar, baixar, excluir e mais.
  • ⋮ em cada item abre todas as ações daquele item.
  • O botão + cria pasta ou arquivo e envia arquivos do celular.

No computador

  • Clique seleciona, duplo clique abre, botão direito abre o menu. Ctrl/Shift + clique seleciona vários.
  • Arraste arquivos do computador para a janela para enviar (ou para cima de uma pasta, para enviar para dentro dela).
  • Arraste itens para uma pasta ou para o caminho do topo para mover. Com Ctrl ou Alt, copia.
  • Clique nos títulos das colunas (Nome, Tamanho, Modificado) para ordenar.

Ações

AçãoComo
Ver / editarAbrir um arquivo mostra imagens, vídeos, áudios e PDFs. Textos e código abrem num editor: Ctrl+S ou o botão Salvar. Se o arquivo mudar em outro lugar enquanto está aberto, o app avisa antes de sobrescrever.
Copiar / moverCopiar ou Recortar, abrir a pasta de destino e tocar em "Colar aqui" / "Mover para cá". Funciona entre o servidor e o Drive, nos dois sentidos.
EnviarBotão de enviar (↑), o + no celular, ou arrastar. Se já existir um arquivo com o mesmo nome, o novo vira "nome (1)".
BaixarArquivo: baixa direto. Pasta ou vários itens do servidor: um .tar.gz.
BuscarLupa: digitar filtra a pasta atual; "Buscar em subpastas" (ou Enter) procura em tudo abaixo. node_modules e .git ficam de fora.
OutrosRenomear, duplicar, excluir, propriedades (tamanho da pasta, permissões), copiar caminho, adicionar aos favoritos, abrir terminal aqui, mostrar ocultos, lista ou grade.

Excluir no servidor é definitivo: não existe lixeira. No Google Drive, os arquivos excluídos vão para a lixeira do Drive.

06 Google Drive (rclone)

O gerenciador de arquivos mostra qualquer nuvem configurada no rclone: Google Drive, OneDrive, Dropbox, S3 e outras. O rclone já vem instalado no Docker. A configuração fica em /root/.config/rclone, que sobrevive aos deploys.

Configurar o Google Drive

Abra um terminal no app e rode:

rclone config
  1. n (novo remote) e dê um nome, por exemplo gdrive.
  2. Em "Storage", digite drive.
  3. client_id e client_secret: aperte Enter (vazio).
  4. scope: 1 (acesso completo). Nas perguntas seguintes, Enter; em "Edit advanced config", n.
  5. "Use web browser to automatically authenticate?": responda n, porque o servidor não tem tela. O rclone mostra um comando rclone authorize "drive" "...".
  6. Num computador com o rclone instalado, rode esse comando. O navegador abre: faça login no Google e copie o código que aparecer no terminal do computador.
  7. Cole o código no MeuTerminal (config_token>). Em "Shared Drive", n. Depois y para confirmar e q para sair.

Pronto: abra (ou atualize) uma aba Arquivos. O gdrive aparece em "Nuvem" no painel lateral.

Sem computador? No passo 5, responda y. O rclone mostra um link http://127.0.0.1:53682/auth…: abra esse link numa aba de navegador do MeuTerminal, que roda no próprio servidor, e faça o login lá. O Google às vezes bloqueia login nesse tipo de navegador; se bloquear, use o método com o computador.

07 Agentes e MCP

O MeuTerminal tem um servidor MCP próprio. Com ele, agentes que rodam nos terminais do app (Claude Code, Codex…) conseguem controlar o app: abrir uma página para você ver o resultado, tirar print, abrir pastas, avisar quando terminar.

Ligar no Claude Code

  1. Abra ⋮ → Configurações → "Agentes (MCP)" e copie o comando.
  2. Cole e rode num terminal do MeuTerminal (é uma vez só; vale para todos os terminais).
  3. Abra o claude e peça, por exemplo: "roda o projeto e abre no navegador pra eu ver" ou "abre a pasta ~/projetos/loja".

O que o agente consegue fazer

FerramentaPara quê

screenshot / read_pageO agente vê a página (print ou texto) para conferir o resultado.
navigate / close_tabMuda o endereço ou fecha abas de navegador e de arquivos. Abas de terminal só você fecha.
open_folderAbre uma pasta no gerenciador de arquivos (ou num terminal, com view: "terminal"). Aceita o Drive: gdrive:Documentos.

list_tabs / list_portsLista as abas abertas e os projetos rodando.

O MCP só aceita conexões do próprio servidor e com o token do app: nada disso fica exposto na internet.

Com open_url, o agente pode abrir a página ao lado do terminal dele (tela dividida) e pedir para ela recarregar quando os arquivos mudarem. Cada terminal tem o próprio endereço em $MEUTERMINAL_TAB_ID, que o agente usa para saber onde abrir.

Modo vibecoding

Para começar um projeto do zero conversando com a IA:

  1. Abra ⋮ → Novo projeto (vibecoding), ou peça ao agente no terminal: "vamos vibecodar um projeto novo".
  2. Preencha o formulário: nome do projeto, tipo (site HTML, React + Vite, Next.js, API Node ou outro), o que você quer construir, a pasta e o agente (qualquer um com modo UI instalado, ou nenhum - só o terminal).
  3. O app cria a pasta (com git init, se marcado) e divide a tela: a aba de conversa do agente (modo UI, igual ao descrito abaixo) de um lado e prévia ao vivo do outro. Os arquivos do projeto abrem numa aba separada.
  4. O agente recebe o pedido e começa a construir. Em sites HTML a prévia atualiza a cada arquivo salvo; em Vite/Next ela abre sozinha quando o servidor de desenvolvimento sobe.

Abrir projeto anterior: o mesmo formulário lista os projetos já criados - tocar num deles reabre a prévia, os arquivos e a conversa do agente, recriando as abas que tiverem sido fechadas.

Trocar de agente: dentro de um projeto vibecoding, a aba do agente ganha um botão ⇄ "Trocar agente" - cada agente mantém sua própria conversa para aquele projeto, e trocar só muda qual delas está em foco (a prévia e os arquivos continuam os mesmos). Esse botão só aparece em projetos vibecoding, não numa conversa de agente avulsa.

Publicar: com VERCEL_TOKEN configurado (veja a tabela de variáveis), a aba do agente de um projeto vibecoding ganha um botão Publicar que roda a Vercel CLI na pasta do projeto e manda pra produção. Ao terminar, aparece um aviso com o link publicado. Sem o token, o botão não aparece.

Modo UI dos agentes

Além do terminal, o Claude Code e o OpenCode podem rodar numa aba de conversa: mensagens formatadas, cartões de cada ação (comandos, arquivos lidos, edições com diff), subagentes, plano e um painel com uso e custo.

  • Pelo terminal: ao digitar claude (ou opencode), o app pergunta se você quer abrir no modo UI. "Não" segue no terminal, igual a hoje. Em Configurações → "Modo UI dos agentes" dá para escolher "sempre UI", "sempre terminal" ou "perguntar".
  • Pelo menu: ⋮ → Nova conversa com agente abre na pasta da aba atual. O botão de histórico da aba retoma conversas antigas, inclusive as começadas no terminal.
  • Permissões: quando o agente quer rodar um comando ou editar um arquivo, aparece um cartão com [Permitir] e [Negar]. Ações perigosas (rm -rf, sudo, escrever fora da pasta, mexer em credenciais) vêm com alerta. Se você estiver fora do app, chega uma notificação push.
  • Chaves de API, tokens e senhas que aparecem nos comandos e saídas ficam escondidos (sk-p…••••••).
  • O modo UI só funciona com login configurado (AUTH_EMAIL/AUTH_PASSWORD ou PIN).

Notificações no celular

Em ⋮ → Configurações → Notificações, toque em "Ativar neste aparelho". A partir daí, quando o agente usar notify, você recebe a notificação com som mesmo com o app fechado. No iPhone, primeiro instale o app na tela inicial (Compartilhar → Adicionar à Tela de Início) e ative por ele. Com o app aberto na tela, o aviso aparece dentro dele, também com som.

08 Login e verificação em 2 etapas

  • Email e senha (AUTH_EMAIL + AUTH_PASSWORD): o modo recomendado. Trocar a senha desconecta todos os aparelhos.
  • PIN (MEUTERMINAL_PIN): só vale quando email e senha estão vazios.
  • Depois de 5 tentativas erradas, o login fica bloqueado por 15 minutos (LOCKOUT_TIME).

Conectar outro aparelho por QR code

Num aparelho já logado, abra ⋮ → Configurações → Conectar outro aparelho → "Mostrar QR code" e aponte a câmera do celular: ele entra sem digitar a senha. O código vale uma vez só, por 2 minutos.

Ligar o app autenticador (2 etapas)

Com a verificação ligada, o login pede também um código de 6 dígitos do celular, que muda a cada 30 segundos. Funciona com Google Authenticator, Microsoft Authenticator, Authy, 2FAS, Aegis, Bitwarden, 1Password e outros.

  1. Gere a chave. Rode em um destes lugares: 
    cd /app && node scripts/totp-setup.js
    docker compose exec meuterminal node scripts/totp-setup.js
    npm run 2fa
    Ele mostra a chave, o código atual e a linha para o .env.
  2. Cadastre no celular: no app autenticador, "Adicionar conta" → "Inserir chave de configuração", digite a chave (os espaços não importam) e escolha "Baseado em tempo". O código mostrado tem que ser igual ao que o gerador mostrou.
  3. Coloque no servidor: AUTH_TOTP_SECRET=SUA_CHAVE, no .env ou nas variáveis do painel (Coolify etc.).
  4. Reinicie: docker compose up -d (o restart não lê o .env de novo) ou faça um novo deploy no painel.
  5. Teste: todo mundo é deslogado. Entre com email e senha, digite os 6 dígitos (o login é enviado sozinho no sexto).

A chave é uma senha. Guarde num gerenciador de senhas e não compartilhe. Perdeu o celular? Apague AUTH_TOTP_SECRET do servidor e reinicie: o login volta a ser só email e senha.

09 Não perder dados no deploy

No Docker, cada deploy recria o contêiner a partir da imagem: só sobrevive o que está num volume. O docker-compose.yml do repositório já guarda o que importa:

O quêOnde ficaSobrevive ao deploy?
Seus projetos e arquivos na home/root (volume meuterminal-home)Sim
Login do Claude Code, chaves SSH, histórico do bash, ~/.local/rootSim
Programas instalados com npm i -g/root/.npm-globalSim
Configurações (rclone/Drive, starship, gh…)/root/.config → ./configSim
Abas, telas, comandos rápidos, favoritos, logins do navegador/app/data → ./dbSim
Programas instalados com apt install/usrNão
Processos rodando (ex.: npm run dev)memóriaNão: reinicie depois do deploy

Regras de ouro

  • Guarde projetos dentro de /root (a home, ~). Fora dela, nada é salvo.
  • Para ter um programa do apt sempre, adicione-o no Dockerfile do repositório. O Claude Code já vem instalado.
  • Mudanças no docker-compose.yml têm que ir para o GitHub. O painel (Coolify etc.) usa o arquivo do repositório a cada deploy, então uma mudança feita só no painel se perde.
  • Nunca rode docker compose down -v nem apague os volumes no painel: o -v apaga o volume da home.
  • Fechar o app não para nada. O que para os processos é fechar a aba (✕) ou um novo deploy/reinício do servidor. Depois de um deploy, as abas voltam com a tela de antes e um shell novo na mesma pasta.

Backup da home

No servidor (SSH), gera home-backup.tar.gz na pasta atual:

docker run --rm -v "$(docker inspect -f '{{range .Mounts}}{{if eq .Destination "/root"}}{{.Name}}{{end}}{{end}}' meuterminal)":/root -v "$PWD":/backup alpine tar czf /backup/home-backup.tar.gz -C /root .

Coolify: o serviço se chama meuterminal a partir da versão 2.4. Depois do primeiro deploy com esse nome, confira em Configuration se o domínio está ligado ao serviço meuterminal. Confira também se as variáveis do painel usam os nomes da tabela abaixo.

12 Problemas comuns

"claude: command not found"

O Claude Code vem na imagem a partir da versão 2.4: faça o deploy da versão nova. Para instalar na mão, use npm install -g @anthropic-ai/claude-code. O comando npm install claude (sem -g e sem o @anthropic-ai/) instala outro pacote que não tem nada a ver.

"Cannot find module /app/scripts/totp-setup.js"

O servidor está com uma versão antiga. Faça o merge do PR no GitHub e o deploy.

O app não mudou depois do deploy

O app instalado guarda arquivos para abrir rápido. Feche e abra o app de novo (ou recarregue a página). A versão nova é baixada sozinha em segundo plano.

Perdi o que estava na home depois do deploy

Veja Não perder dados: a home só é salva a partir da versão 2.4, com o volume meuterminal-home no docker-compose.yml do GitHub. O que foi perdido antes não volta; daqui para frente fica salvo.

O código de 6 dígitos diz "inválido"

Deixe a data e a hora do celular no automático. No servidor, date -u tem que mostrar a hora certa. Cada código só vale uma vez: espere o próximo.

Fui bloqueado no login

Depois de 5 erros, espere 15 minutos ou reinicie o contêiner.

O Drive não aparece nos Arquivos

Rode rclone listremotes num terminal: o remote tem que aparecer ali. Se aparecer, atualize a aba Arquivos (⋮ → Atualizar) ou abra uma nova.

A aba de navegador fica em branco

Confira se o projeto está rodando (botão de portas) e se o endereço está certo. Em conexão lenta, use qualidade "Leve (4G)".
